## Automated logic tests

Run `npm test` with Node.js 18+.

- Blank and missing values return `NO_DATA`.
- Configured reference-band endpoints are inclusive.
- Values outside the configured bands return `REVIEW`.
- Non-numeric and out-of-input-range values return `INVALID`.
- Missing readings cause an overall `LIMITED` assessment.
- Fully populated out-of-band readings produce `REVIEW`.
- The nominal demo scenario produces `WITHIN`.
- Custom reference bands are respected and invalid lower/upper pairs are rejected.
- Reference-snapshot capture requires a complete, valid saved reading set; current values are compared with the captured snapshot using documented demonstration tolerances. A single snapshot is not a multi-day statistical baseline.
- Missing current readings remain missing in baseline comparison; they are not imputed.
- Saved wellbeing self-reports trigger separate, inspectable flags; combined context is reported only when both baseline and wellbeing evidence exist.
- A one-point heart-rate history is not duplicated or presented as a time trend.
- Static integration tests verify that app.js element IDs exist in index.html and all referenced offline-shell assets exist.

## Mission Replay and synthetic ML

- Mission Replay is deterministic for the same scenario and seed; default profile length is 30 days.
- All replay signals and wellbeing values are generated by project code and labelled `SIMULATED`.
- The active browser-local model is ASTRA-SYNTH-MLP-2, trained only on generated synthetic feature windows. No NASA participant data, clinical dataset, or real astronaut telemetry is used for training.
- The model uses a seven-day rolling window and abstains when there are fewer than seven records, fewer than five of seven vital-sign values for any channel, insufficient self-report values, or more than 25% missing vital-sign cells.
- Missing signal values are never imputed. The model score is a similarity score to the synthetic deviation class, not a clinical probability or medical-risk score.
- MLP v2 uses four generated physiological-deviation families; sensor dropout is handled by the deterministic quality gate and abstention, not by a fifth classifier label.
- The offline JavaScript bundle must expose the same MLP v2 artifact as the JSON file, and the HTML/service worker must reference/cache the v2 bundle.
- The day-to-day heart-rate standard deviation must not be labelled beat-to-beat heart-rate variability (HRV).
- Hold-out metrics are limited to the synthetic data generator and must not be presented as real-world, astronaut, clinical, or operational performance.
- Browser inference has no external model API dependency. Development-time training uses the pinned packages in `requirements-model-training.txt`.
